# Data Dictionary: Electric Vehicle Market Performance & Insights

## Overview
This data dictionary provides comprehensive metadata, column descriptions, data types, and business rules for the datasets used in the **Electric Vehicle Market Performance & Insights** project.

---

## 1. Cleaned Dataset: `EV_Market_Performance_Cleaned.csv`
| Column Name | Data Type | Example Value | Description & Business Rules |
| :--- | :--- | :--- | :--- |
| **`Record_ID`** | String (Categorical) | `EV-1001` | Unique identifier for each vehicle trim and observation record. |
| **`Model_Year`** | Integer (Temporal) | `2024` | Manufacturing and sales release year (2019 to 2025). |
| **`Make`** | String (Categorical) | `Tesla`, `BYD` | Automobile manufacturer / Brand OEM. |
| **`Model`** | String (Categorical) | `Model Y`, `Seal` | Model family designation. |
| **`Model_Variant`** | String (Categorical) | `Model Y Long Range AWD` | Specific trim level (Standard, Long Range, Performance, etc.). |
| **`Vehicle_Category`** | String (Categorical) | `SUV`, `Sedan`, `Hatchback`, `Truck`, `Electric Bus`, `Two-wheeler` | Vehicle classification category. |
| **`Battery_Technology`** | String (Categorical) | `LFP`, `NMC`, `NCA`, `Solid-State`, `Sodium-Ion` | Primary electrochemical cell chemistry utilized in the traction pack. |
| **`Battery_Capacity_kWh`** | Float (Continuous) | `78.5` | Usable traction battery capacity measured in kilowatt-hours (kWh). |
| **`Driving_Range_km`** | Integer (Continuous) | `530` | Official single-charge driving range rated under WLTP / EPA cycles in kilometers. |
| **`Base_Price_USD`** | Integer (Currency) | `44990` | Base manufacturer suggested retail price (MSRP) in United States Dollars. |
| **`Fast_Charge_Time_mins`**| Integer (Continuous) | `25` | DC fast charging duration from 10% to 80% state-of-charge (SoC) in minutes. |
| **`Standard_Charge_Time_hrs`**| Float (Continuous) | `7.2` | AC Level 2 charging duration (0% to 100% SoC) in hours. |
| **`Annual_Sales_Units`** | Integer (Discrete) | `45200` | Total registered unit sales volume for the specified model in that year. |
| **`Sales_Revenue_USD`** | Float (Currency) | `2033548000.00` | Calculated Gross Revenue: `Annual_Sales_Units * Base_Price_USD`. |
| **`Customer_Rating`** | Float (Continuous) | `4.6` | Aggregated customer satisfaction score on a standardized scale of 1.0 to 5.0. |
| **`Energy_Consumption_kWh_100km`** | Float (Continuous) | `16.2` | Energy efficiency: Kilowatt-hours required per 100 kilometers traveled. |
| **`Carbon_Offset_Tons`** | Integer (Continuous) | `85880` | Net annual greenhouse gas emissions avoided relative to equivalent ICE vehicles (metric tons CO2e). |
| **`Manufacturing_Country`**| String (Geographic) | `USA`, `China`, `Germany` | Country of primary assembly / manufacturing facility. |
| **`Production_Region`** | String (Geographic) | `North America`, `Asia-Pacific`, `Europe` | Continental / geopolitical manufacturing region. |
| **`Status`** | String (Categorical) | `Actual`, `Forecast` | Status of data point (Historical actuals vs 2025 strategic market forecast). |
| **`Range_Efficiency_km_per_kWh`** | Float (Calculated) | `6.75` | Distance traveled per unit of stored energy (`Driving_Range_km / Battery_Capacity_kWh`). |
| **`Price_per_km_Range_USD`** | Float (Calculated) | `84.89` | Value metric: Dollar cost per kilometer of driving range delivered. |
| **`Market_Share_Percentage`**| Float (Calculated) | `4.12` | Brand/Model volume as a percentage of total annual global EV registrations. |
| **`Satisfaction_Tier`** | String (Categorical) | `Delighted (4.5 - 5.0)` | Categorical grouping of customer sentiment based on customer rating. |
| **`Range_Category`** | String (Categorical) | `Long Range (450 - 599 km)` | Categorical segmentation by single-charge range capability. |
| **`Price_Segment`** | String (Categorical) | `Mid-Market ($30K - $50K)` | Price positioning segment for portfolio analysis. |

## 2. Battery Technology Summary Dataset: `EV_Battery_Technology_Summary.csv`
| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **`Battery_Technology`** | String | Cell chemistry classification (`LFP`, `NMC`, `NCA`, `Solid-State`, `Sodium-Ion`). |
| **`Model_Year`** | Integer | Model evaluation year. |
| **`Total_Units_Sold`** | Integer | Sum of vehicle units registered with this battery chemistry. |
| **`Total_Revenue_USD`** | Float | Total market revenue generated by vehicles utilizing this technology. |
| **`Avg_Battery_Capacity_kWh`** | Float | Mean battery capacity across active models. |
| **`Avg_Driving_Range_km`** | Float | Mean driving range achieved. |
| **`Avg_Range_Efficiency`** | Float | Mean efficiency in kilometers per kilowatt-hour. |
| **`Avg_Price_USD`** | Float | Mean vehicle price tag across vehicles in this chemistry group. |
| **`Avg_Fast_Charge_mins`** | Float | Mean DC fast charge duration. |
| **`Avg_Customer_Rating`** | Float | Mean customer satisfaction rating. |
